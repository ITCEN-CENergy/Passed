# 추천 정확도 개선 전후 오프라인 검증

이 폴더는 하이브리드 스킬 검증 도입 전후의 추천 품질을 같은 데이터와 같은 점수 정책으로 재현하는 회귀 벤치마크다.

## 판정 기준

- `2 (적합)`: 동일 직무이고 필수 역량을 직접 보유하거나 이력서·자기소개서 원문에서 목표 역량의 완료된 수행 근거가 확인된다.
- `1 (도전 가능)`: 동일 직무이지만 필수 역량 또는 요구 숙련도 한 가지가 부족하다.
- `0 (부적합)`: 직무가 다르거나, 유사 용어만 있고 목표 역량의 직접 수행 근거가 없다.

주 지표는 실제 노출되는 상위 10개 중 `2 (적합)`의 비율인 `Precision@10`이다. 순위 전체 품질은 `NDCG@10`, 잘못 노출된 `0 (부적합)`의 비율은 `과대 추천률@10`, 적합 공고를 얼마나 회수했는지는 `Recall@10`으로 보조 확인한다.

## 데이터 구성

- 10개 직무 프로필
- 프로필별 후보 공고 30개
- 총 사용자-공고 쌍 300개
- 시나리오: 강한 직접 매칭, 문서 근거로 복구되는 누락 스킬, 도전 가능, 의미 유사도 함정, 직무 불일치

이 데이터는 개인정보나 실제 지원 결과를 사용하지 않은 **합성·루브릭 라벨 데이터**다. 알려진 실패 유형을 재현하는 회귀 검증에는 적합하지만, 실제 사용자 전체의 일반화 성능을 증명하는 운영 A/B 테스트를 대체하지 않는다.

## 개선 전후 정의

- 개선 전: 의미 유사도로 제안된 누락 필수 스킬을 모두 보유 스킬처럼 확장한다.
- 개선 후: 동일 ID 매칭을 우선하고, 원문 인용·완료 행동·범위·카테고리 검증을 통과한 누락 스킬만 확장한다.
- 공통 점수 정책: 필수 60점, 우대 20점, 관련 10점, 중요 스킬 10점, 필수 보유율 50% 미만은 추천 후보에서 제외한다.

## 실행

```bash
cd passed-ai
python -m recommendation_evaluation.run_benchmark
python -m unittest recommendation_evaluation.test_benchmark -v
```

원본 데이터는 `data/recommendation_benchmark.csv`, 집계 결과는 `results/aggregate_metrics.csv`, 프로필별 결과는 `results/profile_metrics.csv`, 추천 상세는 `results/top10_recommendation_details.csv`에서 확인한다.
