# Features

각 폴더는 사용자가 수행하는 기능을 기준으로 나눕니다. 백엔드의 엔티티나 테이블을
그대로 복제하지 않으며, 기능 전용 API 호출·컴포넌트·훅은 해당 기능 안에 함께 둡니다.

- `auth`: 로그인, 로그아웃, 인증 세션
- `user`: 사용자 프로필과 희망 직무
- `resume`: 이력서 작성과 관리
- `skill`: 보유 역량과 근거 관리
- `job-posting`: 채용 공고 탐색과 상세 조회
- `cover-letter`: 자기소개서 문항과 답변 작성
- `roadmap`: 분석 결과 기반 학습 계획과 진행률
- `recommendation`: 스킬 기반 채용 공고 추천과 결과 리포트

기능 간 직접 참조는 최소화하고, 공통 코드는 `shared`로 승격합니다.
